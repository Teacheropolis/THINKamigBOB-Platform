## 2. Exact Prototype Boundary

The proposed prototype is limited to class-wide teacher configuration for one authenticated class context.

### Included only after every required decision is explicitly approved

- Grade 3, Grade 4, and Grade 5 catalog presentation;
- verified Goal organizers;
- verified student-startable Activity Missions within those Goals;
- verified Side Path topics and Side Path activities;
- one or multiple active Goal organizers;
- no more than three verified primary Activity Mission Start choices;
- secondary Side Path choices that do not consume or bypass the three-primary-choice ceiling;
- one class-wide current classroom focus;
- class-wide Builder and Workshop availability where independently authorized;
- atomic class-wide confirmation;
- honest replacement and removal behavior;
- shared teacher-to-student projection;
- Student Dashboard rendering of only the effective approved class-wide choices; and
- Continue-current-work protection independent of the Start set.

### Explicit exclusions

- individual-student assignments or overrides;
- small-group assignments;
- cross-grade assignments;
- Grade 6;
- production automation;
- inferred recommendations or personalization;
- analytics, grading, ranking, or behavior scoring;
- Google API or Google Workspace ingestion;
- production Mission Distribution beyond the exact approved class-wide boundary;
- changes to Builder or Workshop internals; and
- reinterpretation of PB-002I Today’s Mission as assignment or distribution state.
