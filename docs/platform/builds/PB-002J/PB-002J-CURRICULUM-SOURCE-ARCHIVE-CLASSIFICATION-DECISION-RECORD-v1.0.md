## 5. Source-to-Display-Name Traceability

Clear spelling, capitalization, spacing, punctuation, and apostrophe errors may be corrected in future catalog **display names** when the correction does not change instructional meaning.

Approved examples include:

| Original source wording | Normalized catalog display name |
|---|---|
| `Create Transporation` | `Create Transportation` |
| `Community Alarm Systeml` | `Community Alarm System` |
| `LED Playground Lightning` | `LED Playground Lighting` |

Underscores used in source paths in place of apostrophes may likewise be normalized for display where the intended wording is clear.

Every normalized display name must preserve a traceable reference to:

- the original archive identity;
- the exact original source path and filename;
- the original source wording;
- the approved normalized display name;
- the reason for normalization;
- the approving authority and approval date when authoritative adoption occurs; and
- the applicable stable catalog identity and version once those decisions exist.

Normalization must not:

- rename or rewrite the original archive file;
- silently replace source evidence;
- change curriculum meaning;
- create a new Activity Mission;
- conceal a conflict between sources; or
- imply that identity/version or maintenance authority has been assigned.

If the intended correction is not clear or would change meaning, the display name must remain unresolved pending curriculum-owner confirmation.
